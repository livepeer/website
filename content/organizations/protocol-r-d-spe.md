A Special Purpose Entity is a focused, community-funded team contributing to the Livepeer ecosystem — an entity running a themed program for which it has expertise, funded through the treasury to deliver against it.

Protocol R&D's remit is the chain itself: consensus participation, reward mechanics and token supply. Work that changes protocol behaviour rather than the software around it.
